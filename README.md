| `style.css` | Gaya untuk halaman privasi dan syarat |

## Cara menayangkan (GitHub Pages)

1. Buat repositori publik bernama `usernamekamu.github.io`.
2. Unggah semua file di atas lewat *Add file → Upload files*, lalu *Commit changes*.
3. Buka *Settings → Pages*, pilih *Deploy from a branch*, branch `main`, folder `/ (root)`, lalu simpan.
4. Situs aktif di `https://usernamekamu.github.io`.

## Domain kustom (is-a.dev)

Daftarkan `icandomore.is-a.dev` lewat pull request ke `is-a-dev/register`. Setelah PR disetujui, isi *Settings → Pages → Custom domain* dengan `icandomore.is-a.dev` dan centang *Enforce HTTPS*. Jangan membuat file `CNAME` sendiri sebelum PR disetujui.

## Memperbarui isi

Ganti file dengan nama yang sama lewat *Add file → Upload files*. Jangan hapus file `CNAME` yang dibuat GitHub setelah domain kustom aktif.
